# DoPie 1.2.0

This release lets several people run one DoPie folder from a shared folder.

## Included

- Personal preferences, favourites, and installed Slices for each person running the same DoPie folder
- Sources, access tokens, the update repository, catalogues, and Slice dependencies shared by everyone using the folder
- Launches from any drive letter, UNC path, or mount point, on Windows and Linux alike
- Updates, first-run setup, and package preparation that are safe when several people start DoPie at once
- A version rollback only from the start that switched to that version
- Source and access token changes that keep changes made by other people
- The first person to start DoPie 1.2.0 on an existing copy keeps its installed Slices and preferences
- Running from a shared folder needs the launch scripts of a DoPie 1.2.0 download; in-app updates keep a copy's existing launch scripts
