# DoPie 1.3.0

This release lets Slices with the same ID coexist across Sources and adds Source tabs to the Slice Manager.

## Included

- Separate installations, updates, rollback versions, favourites, recent items, and assets for each Source's Slices
- Existing installations and rollback versions moved into Source-specific folders automatically
- Source tabs in Installed and Available, with an All tab and a tab for each enabled Source
- Installed Slices from disabled or removed Sources remain accessible through All
- Source ID changes preserve installed Slices, favourites, recent items, and assets for everyone using the shared DoPie folder
