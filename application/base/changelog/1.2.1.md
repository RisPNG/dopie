# DoPie 1.2.1

This release keeps DoPie's runtime and packages on each computer, so a shared DoPie folder can sit at a long network path.

## Included

- The runtime and the packages of DoPie and its Slices kept in each computer's cache instead of the DoPie folder
- Shared folders at network paths of up to about 140 characters on Windows without long path support, with faster starts
- First-time setup on Windows that shows its progress and keeps its window open with the error when it fails
- Running from a shared folder needs the launch scripts of a DoPie 1.2.1 download or export; in-app updates keep a copy's existing launch scripts
