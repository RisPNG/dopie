# DoPie 1.0.0

The first stable release establishes DoPie as a portable, source-run Pie and Slice platform for Linux and Windows.

## Included

- Responsive Library, Favorites, recent ordering, and optional available Slice cards
- Slice Manager with installed, available, and trusted Source views
- GitHub and Forgejo Sources, including private repositories
- One-time password authorization for transferable private Source profiles
- Folder-local encrypted credentials, preferences, catalogues, updates, environments, and Slice data
- Standard Slice interfaces with isolated environments, typed inputs, assets, progress, logs, results, and cancellation
- Verified versioned Slice installation, updates, uninstall, and rollback
- Staged application updates with startup health rollback and version-aware What’s New screens
- Portable Windows and Linux launchers with visible first-time setup and terminal-free normal launches
- Linux, Windows, or combined portable exports that omit runtimes and installed Slices
- Consistent light, dark, and automatic operating-system themes
- Cross-platform application branding and native window integration
