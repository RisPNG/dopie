# DoPie 1.2.2

This release lets everyone using a shared folder on Windows see the Sources and updates that one person set up in it.

## Included

- Imported Sources, access tokens, and shared preferences that everyone using a shared folder on Windows can read
- Updates prepared by one person that everyone using a shared folder on Windows can start
- On Windows, the person who applied this update to a shared folder, or who first started a shared folder set up with DoPie 1.2.0 or 1.2.1, runs `icacls "<DoPie folder>" /reset /T /C` once so that everyone can read the files DoPie created for them
