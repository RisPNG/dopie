# DoPie 1.2.3

This release lets standard Slices ask for several files in one input.

## Included

- Multiple file inputs declared with `type = "files"`, passed to the Slice as a list of paths
- Files added from any number of folders, with repeats skipped and selected files removable before running
- Required-field validation that asks for at least one file
- Slices that use `files` inputs need DoPie 1.2.3 or later
