# DoPie 1.1.0

This release makes Source catalogues and Slice updates feel immediate while keeping background activity lightweight.

## Included

- Update actions beside Open for installed Slices with newer versions
- Source-matched update detection so updates only come from the original Source
- Immediate targeted catalogue refreshes after Source changes
- Cached catalogue display followed by background refresh when stale
- Low-frequency refreshes while the Library is active and when returning to DoPie
- Coalesced refresh requests that prevent overlapping Source checks
- Revision-aware catalogue caching that avoids downloading unchanged indexes
