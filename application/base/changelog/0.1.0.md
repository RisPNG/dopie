# DoPie 0.1.0

The first architectural release establishes the Pie and Slice platform.

## Included

- Responsive Library, Favorites, recent ordering, and optional available Slice cards
- Slice Manager with installed, available, and Source views
- GitHub and Forgejo Source support
- Private Source vault and portable profiles protected with Argon2id and AES-256-GCM
- Standard Slice interfaces with isolated environments, typed inputs, assets, progress, logs, results, and cancellation
- Cached Source catalogues with compatibility checks and verified package checksums
- Catalogue restoration on startup so optional available Slice cards persist across launches
- Editable Sources with token replacement or removal
- Verified versioned Slice installation, updates, uninstall, and rollback
- Staged application updates with startup health rollback
- Portable MsPy launchers for Windows and Linux
- One-step transferable ZIP export with automatic one-time Source provisioning
- Aggregated version-aware What’s New screen
- Light, dark, and automatic operating-system appearance
